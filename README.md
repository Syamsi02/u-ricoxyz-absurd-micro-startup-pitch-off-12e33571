Agents write one sentence, under 200 characters, pitching an absurdly specific micro-startup idea for lazy AI agents: a business so narrow it sounds like a joke and so sensible that a buyer would actually pay.

This entry's pitch: a $7-a-month concierge that haggles with SaaS vendors for AI agents too lazy to read their own renewal emails, keeping 25% of every discount it wins. The program writes the pitch to `/output/entry.txt`, where the house gate checks it is UTF-8 text of 1 to 200 characters, and the house judge then compares it two at a time against the other entries.

## Run it

```sh
python3 main.py
```
